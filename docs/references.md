# References

Accessed 2026-11-17 unless a version or data date is specified.

1. OpenFootball. “UEFA Champions League.” Match-result data repository. https://github.com/openfootball/champions-league
2. OpenFootball. “Football.TXT Specification.” Score notation and source format. https://openfootball.github.io/spec/
3. UEFA. “How the new Champions League format works.” Competition-format explanation for the 36-team league phase introduced in 2024/25. https://www.uefa.com/uefachampionsleague/news/0290-1b9c211303c8-e419a4471514-1000/
4. Gneiting, T. and Raftery, A. E. (2007). “Strictly Proper Scoring Rules, Prediction, and Estimation.” Journal of the American Statistical Association, 102(477), 359–378. https://doi.org/10.1198/016214506000001437
5. scikit-learn developers. “LogisticRegression.” scikit-learn API reference. https://scikit-learn.org/stable/modules/generated/sklearn.linear_model.LogisticRegression.html
6. jsulz. “FIFA23: FIFA 15–23 player, coach, and team datasets.” Hugging Face dataset card and files. The card reports all update coverage from 2015-09-10 through 2023-01-13 and says the data was scraped from SoFIFA. The project’s smaller legacy CSV audit and the unaudited 5.6 GB all-updates file are described in docs/sofifa_research.md. https://huggingface.co/datasets/jsulz/FIFA23
7. soccerdata. “SoFIFA Reader.” Documentation for reading versions, updates, teams, and players. This project did not use it to scrape live data. https://soccerdata.readthedocs.io/en/latest/reference/sofifa.html
8. StatsBomb. “Open Data.” Public selected match data and lineups; its coverage is not a complete UCL lineup panel. https://github.com/statsbomb/open-data
9. UEFA. “Fixtures & results — UEFA Champions League.” Official human-readable competition schedule/results page. https://www.uefa.com/uefachampionsleague/fixtures-results/
10. UEFA. “General Terms and Conditions.” The terms prohibit automated scraping/collection of site content. https://www.uefa.com/termsconditions/
11. OpenFootball. “UEFA Champions League.” Current structured public repository; CC0-1.0 license. The repository reviewed for the manual prediction interface had season folders through 2025/26 and did not provide an established automatically updated 2026/27 fixture feed. https://github.com/openfootball/champions-league

The SoFIFA-derived player datasets are third-party scraped data. Dataset-card license fields do not by themselves settle rights in the underlying source-derived content; verify applicable terms before redistributing player records.
