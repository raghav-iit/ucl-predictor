Can pre-match signals improve the forecast of a Champions League result?

For each fixture, estimate the probabilities of a home win, draw or away win using only information available before kickoff. The target is regulation time; extra time, penalties, aggregate score and progression are separate questions.

The study compares a training-period outcome-frequency baseline with three controlled feature sets. It tests whether historical team performance, Elo strength and recent form improve probabilistic forecasts on later matches.

Add signal in controlled steps.

One regularized multinomial Logistic Regression family and one common scoring protocol. Each model adds a feature group so its contribution can be compared.

SHARED PIPELINE

Median imputation → standard scaling → Logistic Regression (lbfgs, L2), C = 0.003, max_iter = 2,000, seed 335. C was selected on validation and applied consistently. An earlier C = 1 run had already exposed final-test results; interpret the final comparison cautiously.

Chronological by design. Comparable at every step.

Future seasons are held out in time. Every compared system is scored on common matches, and preprocessing is fitted on training data only.

Log loss PRIMARY

Penalizes assigning too little probability to the observed class, especially confident errors.

Multiclass Brier PRIMARY

Average squared H/D/A probability error per match. Lower is better for both primary metrics.

Secondary evidence

Accuracy, per-class and macro precision/recall/F1, confusion matrices and one-vs-rest reliability bins show misses and probability behavior.

One validation window and one final period—not repeated rolling-origin evaluation. The final test crosses the 2024/25 format change; knockout subsets are small, with no uncertainty intervals.

Class-wise errors show the draw blind spot.

Across the 503-match final test, none of Models A, B or C assigned a draw the highest probability. Model C predicted 0 of the 87 actual draws as draws. This is a serious class-specific weakness, not a claim that all 503 predictions were wrong: the confusion matrix also records correct home and away predictions. Despite the draw weakness, all three models improve on the baseline in both primary aggregate metrics, log loss and Brier score.

Why not rebalance the classes?

Draws were 21.4% of training and 20.8% of validation. Balanced class weights produced 13 draw predictions and 5.8% draw recall, but worsened both primary metrics and accuracy, so they were not selected.

Read these results with their limits.

Only one validation window and one final period were used. The final test crosses a competition-format change; no uncertainty intervals are available. The C = 0.003 choice followed validation, but an earlier C = 1 test run had already been viewed. Team histories are left-censored, and the unweighted models under-predict draws.
